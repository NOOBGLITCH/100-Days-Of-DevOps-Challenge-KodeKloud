# Ansible: Configure Apache Web Server and `index.html`

The `inventory` file is already available on the **jump host** at:

```bash
/home/thor/ansible/inventory
```

We need to create:

```bash
/home/thor/ansible/playbook.yml
```

The playbook will:

1. Install `httpd` on all app servers
2. Start and enable the `httpd` service
3. Create `/var/www/html/index.html`
4. Add the welcome message at the **top** using `lineinfile`
5. Set owner/group to `apache`
6. Set permissions to `0655`

---

# Steps

## 0. Move into the Ansible directory

```bash
cd /home/thor/ansible
ls
```

---

## 1. Check the inventory

```bash
cat inventory
```

Make sure all required app servers are present

---

## 2. Create `playbook.yml`

```bash
touch playbook.yml
```

Open it:

```bash
vi playbook.yml
```

Add:

```yaml
---
- name: Configure Apache web servers
  hosts: all
  become: true
  gather_facts: false

  tasks:

    - name: Install httpd
      ansible.builtin.yum:
        name: httpd
        state: present

    - name: Start and enable httpd
      ansible.builtin.service:
        name: httpd
        state: started
        enabled: true

    - name: Create index.html
      ansible.builtin.copy:
        dest: /var/www/html/index.html
        content: |
          This is a Nautilus sample file, created using Ansible!
        owner: apache
        group: apache
        mode: '0655'

    - name: Add welcome message at the top
      ansible.builtin.lineinfile:
        path: /var/www/html/index.html
        line: 'Welcome to xFusionCorp Industries!'
        insertbefore: BOF
```

---

## 3. Run the Playbook

Use the exact validation command:

```bash
ansible-playbook -i inventory playbook.yml
```

Expected tasks:

```text
TASK [Install httpd]
changed/ok

TASK [Start and enable httpd]
changed/ok

TASK [Create index.html]
changed

TASK [Add welcome message at the top]
changed
```

The final recap should have:

```text
failed=0
unreachable=0
```

---

## 4. Verify the File

Check the content on all servers:

```bash
ansible all -i inventory -m shell -a "cat /var/www/html/index.html"
```

Expected:

```text
Welcome to xFusionCorp Industries!
This is a Nautilus sample file, created using Ansible!
```

The welcome message must appear **first**

---

## 5. Verify Ownership and Permissions

```bash
ansible all -i inventory -m shell -a "ls -l /var/www/html/index.html"
```

Expected:

```text
-rw-r-xr-x ... apache apache ... /var/www/html/index.html
```

`0655` means:

```text
Owner  → rw-
Group  → r-x
Others → r-x
```

# Good to Know?

### `lineinfile` Module

* Used to add, remove, or modify a specific line in a file
* `line` specifies the text to add
* `insertbefore: BOF` means **Beginning Of File**
* This makes the new line appear at the top

### `copy` Module

* `content` allows you to create a file directly from the playbook
* `owner` controls the file user
* `group` controls the file group
* `mode` controls file permissions

### Apache Service

```yaml
state: started
enabled: true
```

means:

* Start Apache immediately
* Enable Apache to start automatically after reboot

### Final File

```text
/var/www/html/index.html
```
