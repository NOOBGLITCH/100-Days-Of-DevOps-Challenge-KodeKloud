# Deploy MySQL with Persistent Volume and Secrets on Kubernetes

The Nautilus DevOps team needed to deploy a MySQL database on the Kubernetes cluster using persistent storage and Kubernetes Secrets for database credentials.

## Requirements

* Create a **PersistentVolume** named `mysql-pv` with capacity `250Mi`
* Create a **PersistentVolumeClaim** named `mysql-pv-claim` requesting `250Mi`
* Create a **Deployment** named `mysql-deployment`
* Mount the PersistentVolume at `/var/lib/mysql`
* Create a **NodePort** Service named `mysql` using nodePort `30007`
* Create three Secrets:

  * `mysql-root-pass`
  * `mysql-user-pass`
  * `mysql-db-url`
* Configure MySQL environment variables using `secretKeyRef`

# Steps We Performed

## 1. Create the Secrets

Create **`k3s-secret.yaml`**

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: mysql-root-pass
type: Opaque
stringData:
  password: YUIidhb667
---
apiVersion: v1
kind: Secret
metadata:
  name: mysql-user-pass
type: Opaque
stringData:
  username: kodekloud_joy
  password: ksH85UJjhb
---
apiVersion: v1
kind: Secret
metadata:
  name: mysql-db-url
type: Opaque
stringData:
  database: kodekloud_db8
```

Apply it:

```sh
kubectl apply -f k3s-secret.yaml
```

---

## 2. Create the PersistentVolume

Create **`k3s-pv.yaml`**

```yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: mysql-pv
spec:
  capacity:
    storage: 250Mi
  accessModes:
    - ReadWriteOnce
  persistentVolumeReclaimPolicy: Retain
  storageClassName: manual
  hostPath:
    path: /mnt/mysql
```

Apply it:

```sh
kubectl apply -f k3s-pv.yaml
```

---

## 3. Create the PersistentVolumeClaim

Create **`k3s-pvc.yaml`**

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: mysql-pv-claim
spec:
  storageClassName: manual
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 250Mi
```

Apply it:

```sh
kubectl apply -f k3s-pvc.yaml
```

---

## 4. Create the Deployment and Service

Create **`k3s-deployment.yaml`**

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: mysql-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: mysql
  template:
    metadata:
      labels:
        app: mysql
    spec:
      containers:
      - name: mysql
        image: mysql:latest
        ports:
        - containerPort: 3306
        env:
        - name: MYSQL_ROOT_PASSWORD
          valueFrom:
            secretKeyRef:
              name: mysql-root-pass
              key: password
        - name: MYSQL_DATABASE
          valueFrom:
            secretKeyRef:
              name: mysql-db-url
              key: database
        - name: MYSQL_USER
          valueFrom:
            secretKeyRef:
              name: mysql-user-pass
              key: username
        - name: MYSQL_PASSWORD
          valueFrom:
            secretKeyRef:
              name: mysql-user-pass
              key: password
        volumeMounts:
        - name: mysql-storage
          mountPath: /var/lib/mysql
      volumes:
      - name: mysql-storage
        persistentVolumeClaim:
          claimName: mysql-pv-claim
---
apiVersion: v1
kind: Service
metadata:
  name: mysql
spec:
  type: NodePort
  selector:
    app: mysql
  ports:
  - port: 3306
    targetPort: 3306
    nodePort: 30007
```

Apply it:

```sh
kubectl apply -f k3s-deployment.yaml
```

# Good to Know?

### PersistentVolume (PV)

* Provides persistent storage independent of Pod lifecycle.
* Can be reused through PersistentVolumeClaims.

### PersistentVolumeClaim (PVC)

* Requests storage from a matching PersistentVolume.
* Automatically binds when capacity and access modes match.

### Kubernetes Secrets

* Securely store sensitive data such as passwords.
* Inject values into Pods using `secretKeyRef`.

### MySQL Environment Variables

* `MYSQL_ROOT_PASSWORD` – Root account password.
* `MYSQL_DATABASE` – Database created during initialization.
* `MYSQL_USER` – Regular database user.
* `MYSQL_PASSWORD` – Password for the regular user.

### NodePort Service

* Exposes MySQL outside the cluster on a fixed port.
* Routes traffic to port `3306` inside the container.
