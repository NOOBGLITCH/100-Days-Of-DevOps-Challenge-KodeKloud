# Ansible Conditional File Deployment

An inventory file is already placed under `/home/thor/ansible` directory on the jump host, with all Stratos DC app servers included. Create a playbook `/home/thor/ansible/playbook.yml` and use Ansible's `when` conditional statements to perform the tasks below.

-   Copy `blog.txt` from `/usr/src/security` on the jump host to **App Server 1** under `/opt/security`. Owner/group: `tony`, permissions: `0777`.
-   Copy `story.txt` from `/usr/src/security` on the jump host to **App Server 2** under `/opt/security`. Owner/group: `steve`, permissions: `0777`.
-   Copy `media.txt` from `/usr/src/security` on the jump host to **App Server 3** under `/opt/security`. Owner/group: `banner`, permissions: `0777`.

> **Note:** Use the `ansible_nodename` variable from gathered facts with `when` conditions. The play must target `hosts: all`. Validation will run: `ansible-playbook -i inventory playbook.yml`.

## Steps

0.  Navigate to the Ansible directory and verify the inventory:

    ```sh
    cd /home/thor/ansible
    cat inventory
    ls /usr/src/security/
    ```

1.  Create the playbook:

    ```sh
    vi playbook.yml
    ```

2.  Add the following content to `playbook.yml`:

    ```yaml
    ---
    - name: Deploy security files conditionally
      hosts: all
      become: true
      gather_facts: true

      tasks:
        - name: Ensure /opt/security directory exists
          ansible.builtin.file:
            path: /opt/security
            state: directory
            mode: '0755'

        - name: Copy blog.txt to App Server 1
          ansible.builtin.copy:
            src: /usr/src/security/blog.txt
            dest: /opt/security/blog.txt
            owner: tony
            group: tony
            mode: '0777'
          when: ansible_nodename == "stapp01"

        - name: Copy story.txt to App Server 2
          ansible.builtin.copy:
            src: /usr/src/security/story.txt
            dest: /opt/security/story.txt
            owner: steve
            group: steve
            mode: '0777'
          when: ansible_nodename == "stapp02"

        - name: Copy media.txt to App Server 3
          ansible.builtin.copy:
            src: /usr/src/security/media.txt
            dest: /opt/security/media.txt
            owner: banner
            group: banner
            mode: '0777'
          when: ansible_nodename == "stapp03"
    ```

3.  Run the playbook:

    ```sh
    ansible-playbook -i inventory playbook.yml
    ```

4.  Verify deployment on each server:

    ```sh
    # On stapp01
    ssh tony@stapp01 "ls -la /opt/security/blog.txt && cat /opt/security/blog.txt"

    # On stapp02
    ssh steve@stapp02 "ls -la /opt/security/story.txt && cat /opt/security/story.txt"

    # On stapp03
    ssh banner@stapp03 "ls -la /opt/security/media.txt && cat /opt/security/media.txt"
    ```

## Good to Know

### Ansible Conditionals (`when`)

-   **Purpose**: Execute tasks only when specific criteria are met, enabling selective operations within a single play.
-   **Fact-Based Conditions**: Variables like `ansible_nodename`, `ansible_hostname`, and `ansible_distribution` are commonly used for host-specific logic.
-   **Boolean Evaluation**: The `when` clause evaluates as a Jinja2 expression; no `{{ }}` braces are needed inside the condition itself.
-   **Skip Reporting**: Tasks that fail their `when` condition are reported as "skipped" in playbook output, providing clear visibility into what was excluded.

### Key Ansible Facts for Host Identification

-   **ansible_nodename**: The system's nodename as returned by the `uname -n` command; typically matches the inventory hostname in Stratos DC environments.
-   **ansible_hostname**: The short hostname of the remote system.
-   **inventory_hostname**: The alias or name as defined in the Ansible inventory file.
-   **gather_facts**: Must be set to `true` (default) for fact-based variables to be available; setting it to `false` will cause `when` conditions relying on facts to fail.

### Ansible Copy Module Essentials

-   **src Path**: When an absolute path is provided, the file is sourced from the **control node** (jump host), not the managed node.
-   **Ownership**: The `owner` and `group` parameters require `become: true` to set ownership to users other than the connecting SSH user.
-   **Permissions**: Always quote octal modes (e.g., `'0777'`) to prevent YAML from misinterpreting leading zeros.
-   **Directory Prerequisite**: The destination directory must exist before copying; use the `file` module with `state: directory` in a preceding task.

### Best Practices for Conditional Plays

-   **Single Play Pattern**: Using `hosts: all` with `when` conditions is preferred over multiple plays when tasks share common setup (e.g., directory creation).
-   **Idempotency**: Each conditional copy task remains idempotent; re-running the playbook will not overwrite files if content and metadata match.
-   **Scalability**: Adding new servers requires only adding a new conditional task block, keeping the play structure consistent.
-   **Debugging**: Use `ansible-playbook --check -v` to preview which tasks would execute on each host without making changes.
