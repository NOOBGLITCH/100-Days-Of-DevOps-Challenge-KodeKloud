

## 8. Configure Pipeline

Definition:

```
Pipeline script
```

Pipeline:

```groovy
pipeline {
    agent {
        label 'stapp01'
    }

    stages {
        stage('Deploy') {
            steps {
                sh '''
                cd /var/www/html
                git fetch --all
                git reset --hard origin/main || git reset --hard origin/master
                '''
            }
        }
    }
}
```

# Good to Know?

## Jenkins Pipeline

- Pipeline as Code
- Declarative Pipeline
- Scripted Pipeline
- Pipeline from SCM

## Pipeline Components

- Agent
- Stage
- Steps
- Post Actions

## Jenkins Agents

- Execute jobs on remote machines
- Connect using SSH
- Support distributed builds
- Improve scalability

## Deployment Workflow

- Pull latest source code
- Deploy to application server
- Verify application
- Repeat automatically using Jenkins

## Best Practices

- Keep only one responsibility per stage.
- Use labels to target specific agents.
- Store credentials securely in Jenkins Credentials.
- Keep deployment scripts simple and repeatable.
- Never deploy manually if a Pipeline can automate the process.
