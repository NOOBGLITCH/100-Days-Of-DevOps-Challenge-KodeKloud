The DevOps team at **xFusionCorp Industries** decided to set up **Jenkins** as their Continuous Integration and Continuous Delivery (CI/CD) server. The task was to install Jenkins using the **APT package manager**, start the Jenkins service, and create the initial administrator account through the Jenkins web interface.

* Install **Jenkins** using the **APT** utility only.
* Start Jenkins using the **service** command.

# Steps

## 1. Connect to the Jenkins Server

From the **jump-host**, connect to the Jenkins server as the root user.

```sh
ssh root@jenkins
```


---

## 2. Update the Package Repository

```sh
apt update
```

---

## 3. Install Java

> **Note:** Recent Jenkins releases require **Java 21**.

Install Java:

```sh
apt install -y openjdk-21-jre
```

Verify the installed Java version:

```sh
java -version
```

Expected output:

```text
openjdk version "21"
```

If multiple Java versions are installed, select Java 21:

```sh
update-alternatives --config java
```

---

## 4. Install Jenkins

```sh
apt install -y jenkins
```

Verify the installation:

```sh
dpkg -l | grep jenkins
```

Expected output:

```text
ii  jenkins  <version>
```

---

## 5. Start the Jenkins Service

Start Jenkins:

```sh
service jenkins start
```

Check the service status:

```sh
service jenkins status
```

Expected output:

```text
jenkins is running
```

---

## 6. Troubleshoot Jenkins Startup (If Required)

If Jenkins does not start, first check the service status:

```sh
service jenkins status
```

Review the Jenkins log:

```sh
tail -100 /var/log/jenkins/jenkins.log
```

A common issue is an unsupported Java version:

```text
Running with Java 17...
Supported Java versions are: [21,25]
```

In this case, install Java 21 and restart Jenkins:

```sh
apt install -y openjdk-21-jre

service jenkins restart
```

---

## 7. Verify Jenkins

Check the running process:

```sh
ps -ef | grep jenkins
```

Verify Jenkins is listening on port **8080**:

```sh
ss -ltnp | grep 8080
```

Expected output:

```text
LISTEN 0 50 *:8080
```

---

## 8. Retrieve the Initial Administrator Password

```sh
cat /var/lib/jenkins/secrets/initialAdminPassword
```

Copy the password displayed in the terminal.

---

## 9. Access Jenkins

Click the **Jenkins** button provided in the lab environment.

Paste the initial administrator password to unlock Jenkins.

---

## 11. Verify the Installation

Check the Jenkins service:

```sh

```

Verify port **8080**:

```sh

```

# Good to Know?

## Jenkins

* Open-source automation server for CI/CD.
* Automates build, test, and deployment pipelines.
* Supports thousands of plugins for integration with Git, Docker, Kubernetes, AWS, Azure, and many other tools.

## Java Requirement

* Jenkins runs on the Java Virtual Machine (JVM).
* Newer Jenkins releases require **Java 21** or later.
* An older Java version (such as Java 17) prevents Jenkins from starting.

## APT Package Manager

* Used to install and manage software on Ubuntu.
* Automatically resolves package dependencies.
* Keeps installed packages up to date.
