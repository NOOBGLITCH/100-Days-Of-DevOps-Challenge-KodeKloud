# Good to Know?

### Matrix Authorization Strategy

* Allows assigning permissions to individual users.
* Supports both global and project-level security.
* Provides fine-grained access control for Jenkins resources.

### Overall Read Permission

Allows a user to:

* Log in to Jenkins.
* View the dashboard.
* See available jobs.

It does **not** allow building, configuring, or deleting jobs.

### Project-Based Security

Allows permissions to be configured on a per-job basis.

In this task, the `rose` user receives only **Read** access to the existing job.

### Anonymous User

The **Anonymous** account represents unauthenticated visitors.

Removing its permissions prevents public access to Jenkins.
